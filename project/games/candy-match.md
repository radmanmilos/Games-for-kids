# 🐱🐶 Match Game (Candy)

Moved verbatim from `README.md` (2026-10-13 refactor). Keep this file current when the game's behaviour changes; the README only links here.

Purpose:

A simple toddler-friendly swap-to-match game.

Features:

- 4×4 board
- Drag to swap
- Automatic matching
- Cascading pieces
- Score counter
- Star power-ups

Educational goals:

- Pattern recognition
- Planning
- Cause and effect
