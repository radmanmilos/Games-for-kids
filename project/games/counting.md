# 🔢 Animal Counting

Moved verbatim from `README.md` (2026-10-13 refactor). Keep this file current when the game's behaviour changes; the README only links here.

Purpose:

Practice counting and number recognition with familiar animals.

Gameplay:

- Show a picture with a number of animals.
- Offer large, touch-friendly number choices.
- Immediate positive feedback for correct answers, gentle assistance for mistakes.
- Animal cards are scaled to command the stage even at small counts, with a subtle warm stage treatment, while the 64 px number-choice touch floor is preserved.

Educational goals:

- Counting
- Number recognition
