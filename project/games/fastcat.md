# 🐱💨 Брзи мачак (Fastcat)

Purpose:

A Sonic-style 2D auto-runner: the kitty or the explorer-girl sprints forward on her own and the child only steers the timing — jump over rocks, slide under bars, gather coins, and blast through everything with the ⚡ super speed.

Gameplay:

- Auto-run: the character always moves forward at a steady pace; the big JUMP button (right edge) and SLIDE button (left edge) are the only steering, plus the ⚡ button that appears when the meter is full.
- Coins and golden bolts fill the ⚡ meter — but the meter starts FULL on every run (play-test 5), so the first blast is free. A full meter enables super speed — about 3 seconds of invulnerable 2× barrel-roll motion (play-test 8: 4s dragged, 2.5s drained too fast) that smashes rocks and bars while the meter drains; picking up coins/bolts DURING the blast nudges the timer (+0.1s / +0.3s, capped at the full duration) instead of refilling the meter, so a dense arc can no longer keep the blast alive forever.
- Obstacles never kill or fail the run: puddles slow you, rocks must be jumped, slide bars must be ducked, boost pads speed you up for free.
- **Ten themed levels (play-test 4):** Прашума🌺, Тропска долина🦜, Језеро💧, Вулкан🌋, Пећина💎, Мочвара🐸, Ледено доба❄️, Пустиња🌵, Ноћни свет🌙, Острво🏝️. Each level themes the whole course — sky/hills/ground palette — and the cave 💎 hangs a jagged rock CEILING up top instead of sky and clouds (warm torch-lit rock, so it never reads as the navy night), the pickup emoji (the old star coins are now the level's thing, with a glow backing for visibility; the HUD score icon matches), and its own synthesized music loop (explorer-parity engine on the shared `music` bus, runner tempos, no ambient layer). Each level is its own deterministic 25350px course from the same shuffled 7-type deck (calm / rocks / puddle / banner / boost / hills / mixed) with a per-level seed (254 + 101·i), so every hazard family recurs while no two courses are alike; coin arcs teach the jump lines and the low coin lines teach the slide lines.
- Character picker on start: kitty or explorer-girl (same choice as Мала истраживачица). A 🌍 button (top-right) opens the level picker any time — 10 open choices with name + emoji, no locks (explorer parity, toddler-first).
- ♪ music toggle (top-right, under 🌍): shares the explorer's `pkMusic` preference, so one tap mutes music across both games; each level starts its own loop.
- Playable in both orientations (play-test 2 removed the portrait rotate gate); controls: SLIDE bottom-left, JUMP bottom-right, and the ⚡ button stacked well clear above JUMP (12vmin gap — play-test 6) so one thumb reaches both. When the meter is full the ⚡ button is unmistakable (play-test 5): bright gold gradient, thick white ring + glow, a livelier bounce and a rotating rainbow ring behind it, all frozen under reduced motion. Sliding shows the character lying flat on the surface.
- Reaching the goal shows the win modal led by **СЛЕДЕЋИ СВЕТ! ➜** — a CLEAR GREEN button, actually rendered (play-test 7 fixed a CSS `display:none` that had kept it hidden since round 4: the JS only cleared the inline style while the stylesheet's rule won, so the child saw only the replay — and the smoke's `style.display` check was vacuous w.r.t. computed visibility). The button always proceeds: even the last level's click wraps to a new tour from Прашума. Below it sits **ИГРАЈ ПОНОВО as a small round yellow icon-only button** (repeat glyph sized 1.5em in CSS — play-test 8, after the attribute-sized 22px glyph was reported invisible on a phone — label in aria-label/title). After a ~3.5s celebration the win MOVES THE CHILD ON ITSELF to the next level (play-test 5 — a manual button press cancels the countdown). Replay/next resets score, meter and the course, and the level label (bottom-centre) always shows the current level number + name + emoji.
- ⚡ fires on pointerdown (play-test 5), so a second finger's tap instantly triggers super speed even while JUMP/SLIDE are held.

Educational goals:

- Timing
- Reflexes and planning (jump vs slide)
- Cause and effect
- Fine motor skills
