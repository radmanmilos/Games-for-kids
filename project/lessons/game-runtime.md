# Lessons: shared modules, standalone boot, HUD, coloring, audio

Read before touching `game/shared/*`, standalone/boot detection, the kitty HUD, coloring regions or audio helpers. Each entry is a past incident; text is moved verbatim from `AGENTS.md` (Footguns section, 2026-10-13 refactor).

- Shared modules load **after** the game script on all 13 pages that use them (`game/games/x.js` first, then `shared/audio-buses.js`, `viewport.js`, `input.js`, `feedback.js`, `motion.js`, `main.js`). A top-level `function` in a game file becomes `window.<name>`, so a shared module exporting the same name **silently replaces it** — this is how the candy 💡 hint button died: `candy.js`'s `showHint()` was overwritten by `feedback.js`'s `window.showHint(el)`, whose `if (!el) return;` made every click a no-op with no error. Never give a game file a generic top-level name that a shared module also exports (`showHint`, `softPop`, `speakSr`, `gentleMiss`, `successChime`, `celebrateFeedback`); prefix it (`showCandyHint`).
- `window.tone`'s real signature is `(freq, dur, delay, type, vol)` (`game/shared/audio.js:29`) — the `type` string is the **4th** argument, not the 3rd. Passing it in the `delay` slot makes `start` `NaN` and `setValueAtTime` throws, which aborts the rest of the calling function (this is how the Учионица 🏅 finish panel never appeared).
- Standalone boot is single-shot: `game/shared/main.js` calls each page's `startX()` exactly once, guarded by a `started` flag, because the retry path + `DOMContentLoaded` + `load` can all fire. Start functions bind click/pointer listeners, so a second boot doubles every interaction (that bug made one ➡️ tap advance 3 scenes). Never add a second call site or remove the guard.
- Cloudflare Workers serves extensionless URLs: standalone detection must strip `.html` before comparing page names. Never match `'name.html'`.
- Coloring regions: `createColoringRegion` accepts both `r.attrs` and flat fields — never assume `attrs` is always present.
- Kitty HUD button offsets are sacred: music 🔊 at `right:268px`, worlds 🌍 at `right:200px` — do not move them closer or they overlap.
- Every `localStorage` access must be guarded, including preference reads at script top level; an unguarded read at load kills the whole page (task 331).
- Never shuffle with `sort(() => Math.random() - 0.5)`; it is biased and skews answer positions (task 330).
- Touch-interruption smokes assert crash-resistance, not that held input is released; a touch/mouse game needs `touchcancel` handling and a key reset on pause (task 329).
- Never leave an opaque outline `fillRect` underneath transparent art; the white paper-outline belongs only in the procedural fallback branch (task 453; guarded by a smoke).
- The Explorer canvas is never cleared. Anything not repainted every frame (below `groundY`) keeps the very first fallback frame forever and bleeds through the soft edges of ground tiles. A full-canvas repaint is guarded by the poison-canvas smoke (task 453).
- After `ctx.translate(-cameraX, 0)`, `fillRect(0, ...)` is **world** space: a full-screen fill must start at `cameraX`.
- Glyph art is a padded 512x512 canvas. Measure the visible box (`stemBox`) before tiling it or standing it on a floor; drawing the whole canvas leaves gaps and floating sprites. `stemBox` is cached per stem, so tests that stub `Art.imageStem` must clear `stemBoxCache`.
- A smoke that proves only 'draw() does not throw' lets visibly broken screens pass; assert what is drawn (draw-call spies, poison canvas). Scenes are not edge-matched: do not claim seamless tiling without measuring (mirrored tiles are seamless by construction).
- An automated acceptance check cannot judge art: `tile_edge_check` passed flat single-colour ground caps (perfectly matching edges) that were near-invisible in game. Always look at screenshots before accepting generated art; a uniform colour has zero edge difference by definition (task 455).
- Calibrate a detector on the real bad examples before trusting it: the sheet-label rule (5x wide, <14% tall) missed all five real chips (14.5-16.8% tall). Gates are proven by mutation (feed the known-bad file), not by a clean run.
- Do not pin a hand-tuned number in a test (`WALKER_FOOT.crab === 16`): derive it from the sprite bounds (`size/2 - bottomPad*size/512`) so editing a sprite fails the test instead of silently misaligning it.
