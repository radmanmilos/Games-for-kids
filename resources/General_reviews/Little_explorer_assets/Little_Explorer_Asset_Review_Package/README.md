# Little Explorer asset review package

This is a first-pass review package, not a production-ready game asset bundle.

Start here: `REVIEW/TABLE_OF_CONTENT.md`.

The original source atlases are preserved in `00_SOURCE_ATLASES/`. Candidate crops are grouped into numbered family folders. Review sheets are in `REVIEW/`. The CSV is the editable asset-level tracker.

**Placement:** Extract this ZIP inside the repository at:
`resources/General_reviews/Little_explorer_assets/`

This creates:
`resources/General_reviews/Little_explorer_assets/Little_Explorer_Asset_Review_Package/`

Keep the original two atlas files in their existing parent folder. Do not copy candidate crops into `game/` yet. Once candidates are manually reviewed, approved, and technically validated, the implementation-ready assets should be placed in the runtime asset location defined by the current game architecture and asset map.

See `REVIEW/TABLE_OF_CONTENT.md` and `EXTRACTION_LOG.md` before using any candidate.
