## Important

The expansion plan includes product changes that may conflict with existing approved Cat Forest decisions. The local AI must inspect the current repository decision records and obtain explicit approval for unresolved conflicts before implementing those mechanics.

This package is a set of instructions, not an implementation. No repository code, game assets, project task board or status file has been changed by creating it.
