# Little Explorer — Sprite Pack v3 (FINAL, 14 frames)

This reflects the confirmed final file set. Every relationship below
(native vs. mirrored vs. duplicate) was verified pixel-by-pixel against
the actual files, not assumed from filenames.

## Character reference (consistent across all frames)
Chibi-proportioned girl explorer: brown curly shoulder-length hair with
bangs, tan pith helmet with grey-lensed goggles, cream short-sleeve shirt
with brown suspender straps, brown shorts, white ankle socks, brown boots,
small brown shoulder satchel, brown belt with buckle. Flat 2D vector /
soft cel-shaded style, sharp clean outlines, transparent background.
All 14 files share an identical 237×352 canvas with the character
horizontally centered and bottom-aligned to a shared foot baseline —
they drop straight into an animation state machine with no offset
tuning needed.

## Notes on the structure
- **Right-facing set (1–6) is the only fully native art**: three idle
  variants, one walk, one run, one jump.
- **Left-facing set (7, 9–14) is built entirely from mirrors** of the
  right-facing (and #9's own) art, confirmed as exact horizontal flips —
  pixel-identical to a mirror operation, not separately drawn. This is
  a standard, legitimate approach for 2D game sprites (many engines
  flip a single-direction sprite at runtime instead of storing both),
  so gameplay-wise this set is complete and safe to use as-is.
- **#9 (profile_left) is the one native left-facing frame** — #7
  (profile_right) is generated by mirroring it, not the other way
  around.
- **#14 duplicates #10 exactly** (byte-identical) — it exists as a
  second idle-left anchor frame, mirroring how the right side has three
  idle repeats (1, 4, 6). Treat 10 and 14 as interchangeable.
- **#8 (back view)** has no left/right variant — a single back-facing
  pose works for either direction since it reads as symmetric.
